# Contributing / المساهمة

## English
Contributions are welcome: new agent seats, improved checklists, translations, country-specific legal references, and Power BI visuals.

1. Fork the repository and create a branch.
2. Keep every template bilingual (English + Arabic).
3. Never commit real client data – use anonymised or fictional examples only.
4. Cite the law article or regulation for any legal requirement you add.
5. Open a pull request describing what changed and why.

## العربية
نرحب بالمساهمات: وكلاء جدد، تحسين قوائم التقييم، الترجمة، مراجع قانونية لدول أخرى، وتصميمات Power BI.

١. انسخ المستودع (Fork) وأنشئ فرعًا جديدًا.
٢. حافظ على أن يكون كل قالب باللغتين العربية والإنجليزية.
٣. لا ترفع أي بيانات عملاء حقيقية، واستخدم أمثلة مُجهّلة أو افتراضية فقط.
٤. اذكر رقم المادة أو اللائحة لأي متطلب قانوني تضيفه.
٥. افتح طلب دمج (Pull Request) يوضح التغيير وسببه.
