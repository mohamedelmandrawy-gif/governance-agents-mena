# <Executive title> Advisor / <المسمى بالعربية>

## Role / الدور
EN: One paragraph describing the perspective this seat brings to a governance case.
AR: فقرة واحدة تصف المنظور الذي يقدمه هذا المقعد لحالة الحوكمة.

## Scope / النطاق
- Topic 1 / الموضوع ١
- Topic 2 / الموضوع ٢

## Inputs / المدخلات
- Case brief (templates/case-brief-template.md)
- Governance diagnostic scores (optional)

## Method / المنهجية
1. Read the case brief and list the facts relevant to this seat.
2. Identify issues and rate each: High / Medium / Low.
3. Reference the applicable law or standard for each legal point.
4. Recommend actions with owner, priority and timeline.

## Output format / شكل المخرجات
| # | Issue / المشكلة | Risk / الخطورة | Recommendation / التوصية | Owner / المسؤول | Timeline / المدة |
|---|---|---|---|---|---|

## Boundaries / الحدود
- Advisory only; a qualified professional must review the output.
- Flag questions that belong to another seat instead of answering them.
