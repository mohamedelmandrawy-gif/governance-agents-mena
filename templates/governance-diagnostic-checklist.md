# Governance Diagnostic Checklist / قائمة تشخيص الحوكمة

**Scale / المقياس:** 1 = absent / غير موجود · 2 = informal / غير رسمي · 3 = documented / موثق · 4 = implemented / مطبق · 5 = monitored & improved / مراقب ومُحسَّن

| ID | Domain / المجال | Question / السؤال | Score 1–5 / الدرجة |
|---|---|---|---|
| G1 | Board / مجلس الإدارة | Is there a written board charter? / هل يوجد ميثاق مكتوب لمجلس الإدارة؟ | |
| G2 | Board / مجلس الإدارة | Are the Chair and CEO roles separated? / هل دور رئيس المجلس منفصل عن الرئيس التنفيذي؟ | |
| G3 | Board / مجلس الإدارة | Are there independent board members? / هل يوجد أعضاء مستقلون في المجلس؟ | |
| G4 | Committees / اللجان | Is there an audit committee with a charter? / هل توجد لجنة مراجعة لها ميثاق؟ | |
| G5 | Authority / الصلاحيات | Is there an approved delegation of authority matrix? / هل توجد مصفوفة تفويض صلاحيات معتمدة؟ | |
| G6 | Shareholders / المساهمون | Are General Assemblies held and minuted on time? / هل تُعقد الجمعيات العامة وتُحرر محاضرها في مواعيدها؟ | |
| G7 | Family / الأسرة | Is there a family charter or shareholders' agreement? / هل يوجد ميثاق أسرة أو اتفاقية مساهمين؟ | |
| C1 | Control / الرقابة | Is there an internal audit function? / هل توجد وظيفة مراجعة داخلية؟ | |
| C2 | Control / الرقابة | Are financial approval limits enforced in the system? / هل حدود الاعتماد المالي مُفعّلة في النظام؟ | |
| C3 | Risk / المخاطر | Is there a risk register reviewed by the board? / هل يوجد سجل مخاطر يراجعه المجلس؟ | |
| K1 | Compliance / الالتزام | Is there a regulatory obligations register? / هل يوجد سجل للالتزامات التنظيمية؟ | |
| K2 | Compliance / الالتزام | Is there a code of conduct and conflict-of-interest policy? / هل يوجد ميثاق سلوك وسياسة لتعارض المصالح؟ | |
| K3 | Compliance / الالتزام | Are related-party transactions approved and disclosed? / هل تُعتمد تعاملات الأطراف ذات العلاقة ويُفصح عنها؟ | |
| K4 | Compliance / الالتزام | Is there a whistleblowing channel? / هل توجد قناة للإبلاغ عن المخالفات؟ | |
| K5 | Data / البيانات | Is the company assessed against the data protection law? / هل تم تقييم الشركة وفق قانون حماية البيانات الشخصية؟ | |
| O1 | Organisation / التنظيم | Is there an approved organisation chart and job descriptions? / هل يوجد هيكل تنظيمي وأوصاف وظيفية معتمدة؟ | |
| O2 | Organisation / التنظيم | Are HR policies documented and compliant with labour law? / هل سياسات الموارد البشرية موثقة ومتوافقة مع قانون العمل؟ | |
| O3 | Operations / العمليات | Are key processes documented in SOPs? / هل العمليات الرئيسية موثقة في أدلة إجراءات؟ | |

## Scoring / احتساب النتيجة
- Domain score = average of its questions / درجة المجال = متوسط أسئلته
- Gap priority: score ≤ 2 = High, 3 = Medium, ≥ 4 = Low / أولوية الفجوة: ≤ ٢ عالية، ٣ متوسطة، ≥ ٤ منخفضة
- Export scores to `powerbi/sample-data/diagnostic_scores.csv` / انقل الدرجات إلى جدول Power BI
